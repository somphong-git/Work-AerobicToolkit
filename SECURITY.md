# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| < 0.2.0 | No |

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability. Use the
repository's GitHub private security advisory feature. If it is unavailable,
contact a project maintainer through GitHub and include:

- a clear description of the issue;
- affected versions and environments;
- reliable reproduction steps or proof of concept;
- potential impact; and
- suggested mitigation, if known.

We will acknowledge receipt, assess the report privately, and coordinate a fix
before public disclosure where practical.
