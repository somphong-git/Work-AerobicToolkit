# Code of Conduct

## Our pledge

We pledge to make participation in this project welcoming, respectful, and
harassment-free for everyone, regardless of experience level, identity, or
background.

## Expected behavior

- Be respectful, constructive, and open to good-faith feedback.
- Focus discussion on ideas and project outcomes rather than people.
- Give credit for work and respect contributors' time and boundaries.
- Help maintain an inclusive environment for new and experienced contributors.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, intimidation, unwanted
sexual attention, doxxing, and sustained disruption of project discussions are
not acceptable.

## Enforcement

Project maintainers may remove, edit, reject, or escalate contributions and
comments that violate this Code of Conduct. Consequences may include a warning,
temporary restriction, or permanent ban from project spaces.

## Reporting

Report concerns privately through a GitHub private security advisory where
available, or contact a project maintainer through their GitHub profile. Do not
publish sensitive personal information in a public issue.

This policy is adapted from the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
